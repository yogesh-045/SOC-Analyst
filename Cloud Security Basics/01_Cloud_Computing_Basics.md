# ☁️ Cloud Computing Basics

## 📌 What is Cloud Computing?

### Definition

Cloud Computing is the delivery of computing services such as servers, storage, databases, networking, software, and security over the Internet instead of using local computers or on-premises infrastructure.

### Simple Definition

Cloud Computing allows users and organizations to access IT resources over the Internet without owning or maintaining physical hardware.

### Example

Instead of storing files on your laptop, you upload them to **Google Drive** or **Microsoft OneDrive**. Your files are stored on cloud servers and can be accessed from anywhere with an Internet connection.

---

# ☁️ What is Cloud?

The **Cloud** is a network of remote servers hosted on the Internet that store, manage, and process data instead of using local computers or personal devices.

### Example

When you upload a photo to **Google Photos**, the photo is stored on Google's cloud servers instead of your phone.

---

# 🏢 Why Companies Use Cloud?

Organizations use cloud computing because it provides flexibility, scalability, security, and cost savings.

## Reasons

- Easily increase or decrease resources based on demand.
- Reduce hardware and maintenance costs.
- Access applications from anywhere.
- Improve collaboration between employees.
- Provide high availability and disaster recovery.
- Simplify backup and data recovery.
- Deploy applications faster.

### Example

An e-commerce company experiences heavy traffic during a festival sale.

Instead of buying additional physical servers, the company temporarily increases cloud resources and scales them down after the sale.

# ✅ Benefits of Cloud Computing

| Benefit | Description |
|----------|-------------|
| Scalability | Increase or decrease resources based on demand. |
| Cost Savings | Pay only for the resources you use. |
| High Availability | Services remain available even if one server fails. |
| Disaster Recovery | Data can be restored quickly after failures. |
| Accessibility | Access data and applications from anywhere. |
| Automatic Updates | Cloud providers manage updates and patches. |
| Backup | Automatic data backup and recovery options. |
| Security | Cloud providers offer built-in security controls. |

# 🏢 On-Premises vs Cloud

| On-Premises | Cloud |
|-------------|-------|
| Company owns servers | Cloud provider owns servers |
| High upfront cost | Pay-as-you-go pricing |
| Manual maintenance | Managed by cloud provider |
| Limited scalability | Easily scalable |
| Local access | Accessible from anywhere |

# 🔐 Cloud Security Importance

Cloud environments store sensitive information such as:

- Customer data
- Employee information
- Financial records
- Source code
- Business applications

If cloud resources are not secured properly, attackers can steal or expose sensitive data.

# 👨‍💻 SOC Analyst Perspective

- Suspicious IAM activity
- Publicly exposed storage buckets
- Data exfiltration
- CloudTrail alerts
- CloudWatch alerts
- Azure Monitor alerts
- Suspicious API activity

# 📌 Key Points to Remember

- Cloud provides computing services over the Internet.
- Organizations use cloud for flexibility, scalability, and cost savings.
- Cloud providers manage the underlying infrastructure.
- Cloud resources can be accessed from anywhere.
- Security is a shared responsibility between the cloud provider and the customer.
