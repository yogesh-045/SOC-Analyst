# 💬 Cloud Security Interview Questions

These are the most commonly asked Cloud Security interview questions for **SOC Analyst**, **Cybersecurity Analyst**, and **Cloud Security Analyst** roles.

---

# 1. What is Cloud Computing?

## Answer

Cloud Computing is the delivery of computing services such as servers, storage, databases, networking, and software over the Internet instead of using physical infrastructure.

### Simple Answer (Interview)

Cloud Computing allows organizations to use IT resources over the Internet without owning physical hardware.

---

# 2. Why do organizations use Cloud Computing?

## Answer

Organizations use Cloud Computing because it provides:

- Cost savings
- Scalability
- High availability
- Faster deployment
- Easy access from anywhere
- Disaster recovery

---

# 3. What are the benefits of Cloud Computing?

## Answer

Benefits include:

- Cost-effective
- Highly scalable
- Flexible
- Reliable
- Automatic updates
- Business continuity
- Easy backup and recovery

---

# 4. What is the difference between IaaS, PaaS, and SaaS?

| IaaS | PaaS | SaaS |
|------|------|------|
| Provides infrastructure | Provides development platform | Provides ready-to-use software |
| Customer manages OS and applications | Customer manages application code | Cloud provider manages everything except user data and settings |
| High user control | Medium user control | Low user control |

---

# 5. What is IAM?

## Answer

Identity and Access Management (IAM) is a security framework that controls who can access cloud resources and what actions they are allowed to perform.

---

# 6. What is the Principle of Least Privilege?

## Answer

The Principle of Least Privilege (PoLP) means users should be granted only the minimum permissions required to perform their job responsibilities.

---

# 7. What is AWS S3?

## Answer

Amazon S3 (Simple Storage Service) is an object storage service used to securely store and retrieve files, backups, and logs in the cloud.

---

# 8. What is Amazon EC2?

## Answer

Amazon EC2 (Elastic Compute Cloud) is a service that provides virtual servers for running applications in the cloud.

---

# 9. What is AWS CloudTrail?

## Answer

AWS CloudTrail records API calls and user activities performed within an AWS account. It helps with auditing, monitoring, and incident investigations.

---

# 10. What is AWS CloudWatch?

## Answer

Amazon CloudWatch monitors AWS resources, collects logs and metrics, and generates alerts based on predefined conditions.

---

# 11. What is Microsoft Entra ID?

## Answer

Microsoft Entra ID (formerly Azure Active Directory) is Microsoft's cloud-based Identity and Access Management (IAM) service that manages user authentication and access to cloud resources.

---

# 12. What is Microsoft Defender for Cloud?

## Answer

Microsoft Defender for Cloud is a cloud security solution that provides security posture management, threat protection, and security recommendations for cloud resources.

---

# 13. What is Azure Monitor?

## Answer

Azure Monitor collects logs, metrics, and performance data from Azure resources and generates alerts for monitoring and incident response.

---

# 14. What are common cloud security risks?

## Answer

Common cloud security risks include:

- Misconfigured S3 Buckets
- Exposed Credentials
- Public Storage
- Weak IAM Policies
- Data Breaches
- Insider Threats

---

# 15. How would you secure cloud resources?

## Answer

I would secure cloud resources by:

- Enabling Multi-Factor Authentication (MFA)
- Applying the Principle of Least Privilege
- Using strong password policies
- Enabling logging and monitoring
- Encrypting sensitive data
- Performing regular security audits
- Continuously monitoring cloud activities

---

# 16. Why is logging important in cloud security?

## Answer

Logging helps detect suspicious activities, investigate incidents, monitor user actions, and meet compliance requirements.

---

# 17. What is the difference between CloudTrail and CloudWatch?

| CloudTrail | CloudWatch |
|------------|------------|
| Records AWS API calls and user activity | Monitors performance, metrics, logs, and alerts |
| Used for auditing and investigations | Used for monitoring and alerting |

---

# 18. What is the difference between AWS IAM and Microsoft Entra ID?

| AWS IAM | Microsoft Entra ID |
|----------|--------------------|
| Manages AWS users and permissions | Manages Microsoft cloud identities and access |
| AWS-specific | Microsoft cloud identity service |

---

# 19. What would you monitor as a SOC Analyst in the cloud?

## Answer

As a SOC Analyst, I would monitor:

- Login attempts
- Failed authentication events
- IAM changes
- Privilege escalation
- Public storage exposure
- CloudTrail logs
- Azure Monitor alerts
- Security alerts from Microsoft Defender for Cloud
- Suspicious API activity

---
